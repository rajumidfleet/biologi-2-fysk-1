# Biologi 2 & Fysik 1a1 – studieplattform

Interaktiv, statisk studiesajt för E-fokuserad träning i Biologi nivå 2 och Fysik nivå 1a1.

## Funktioner

- separat kursmeny för biologi och fysik
- biologins fyra moment uppdelade i 14 E-fokuserade träningsmoduler
- fysikens åtta moment
- tydlig koppling till övningar, laborationer och Examination 1–3
- active recall med dold förklaring
- självbedömning med 🟢 / 🟡 / 🔴
- lokal kunskapsbank och progress i webbläsaren
- fysikens åttastegsmetod för beräkningar
- responsiv layout för mobil och dator

Sajten saknar ramverk och körs direkt från repository-roten med GitHub Pages.
